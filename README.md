# Landing Page - Psicologia Clínica

Uma landing page responsiva e moderna desenvolvida para captação de pacientes e apresentação de serviços de psicologia clínica e psicanálise. O projeto utiliza conceitos modernos de web design, como o layout assimétrico "Bento Box" e integração direta de agendamento via WhatsApp.

## 🚀 Funcionalidades

* **Design Responsivo:** Layout adaptável para smartphones, tablets e monitores utilizando Media Queries.
* **Bento Grid Layout:** Seção de serviços estruturada com CSS Grid para um visual assimétrico e moderno.
* **Integração com WhatsApp:** Botões de CTA (Call to Action) e link flutuante com mensagens pré-configuradas apontando diretamente para a API do WhatsApp.
* **Scroll Suave:** Navegação âncora fluida entre as seções da página.
* **Páginas Legais Embutidas:** Estrutura isolada para Termos de Uso e Política de Privacidade (adequação LGPD e normas do CFP), mantendo a identidade visual (Header e Footer).
* **Tipografia Acolhedora:** Utilização da Google Font "Nunito" para transmitir fluidez, calma e segurança, alinhada à paleta de cores da área da saúde mental.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica de todas as seções (Hero, Sobre Mim, Serviços, Contato).
* **CSS3:** Estilização pura sem uso de frameworks externos.
  * **Flexbox:** Alinhamento de cabeçalhos, rodapés e cards flutuantes.
  * **CSS Grid:** Construção da estrutura complexa da seção de serviços.
  * **Variáveis e Efeitos:** Sombras sutis (`box-shadow`), gradientes e transições suaves de hover (`transition: ease`).
* **Google Fonts:** Importação e aplicação de tipografia externa.
